Place your background music file in this folder:

  background.mp3

The app will automatically detect and play it when present.
If the file is not here, the app simply runs silently — no errors.

Supported formats: .mp3 (recommended), .ogg, .wav
Volume is set to 40% by default. Music loops continuously.
A 🔊/🔇 toggle button appears in the header only when the file is detected.
